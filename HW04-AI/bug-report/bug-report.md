## Failures that are not defects

Two FR-14 executions fail on Firefox only (`FR14-AUTO-009-01`, `FR14-AUTO-009-02`), with `browserContext.close: Protocol error (Browser.removeBrowserContext)`. The failure occurs during teardown, after the requirement assertions have already passed, and the same datasets pass on the other four projects. This is a Playwright/Firefox environment flake and is deliberately **not** counted as a product defect.

## Evidence scope

Every row above is a UI-level oracle, matching the HW02 scope note that API status codes and database state are not part of the test oracle. Where a fixture stands in for the backend, the row says so explicitly and names the API check that would still be required. No row claims backend behaviour that the recorded run did not observe.

## GitHub issues

All seventeen defects are filed as public issues on the forked SUT repository `ntntran09/eshop-sut`, linked in the table above. Each issue states the requirement it violates, the automated case ids, the expected and actual behaviour, and renders its screenshot inline.

One nuance for review: the screenshots are embedded from the committed report attachments via `raw.githubusercontent.com`, pinned to commits `de66ce0` (defects 1-11) and `fa23a96` (defects 12-17), rather than uploaded as GitHub file attachments — the GitHub API used by `gh` cannot upload issue attachments. They render as images in the issue exactly as an upload would, and the pinned commit keeps them stable, but they are repository files rather than issue-owned uploads.
